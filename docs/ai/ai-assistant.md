# AI Assistant

Sketchware Pro introduces a powerful **AI Assistant** designed to help you build apps faster. It can assist with code generation, fixing errors, and even generating custom blocks.

## Features

*   **Code Generation Assistance:** Ask the AI to write complex logic or boilerplate code for you.
*   **Error Fixing:** detailed explanations and automatic fix suggestions for compilation errors.
 
*   **Conversational Interface:** Chat naturally with the assistant to refine your requests.

## How to use

### Accessing the Chat

You can access the AI Assistant from the main project screen. Tap the **Chat** icon in the bottom navigation bar.

![Access Chat](/img/ai-assistant/access-chat.jpg)

### Chat Interface

The chat interface allows you to interact with the AI. You can type your queries or requests in the message bar at the bottom.

![Chat Interface](/img/ai-assistant/chat-interface.jpg)

### Configuration (API Key)

To use the AI features, you may need to configure your API key. Tap the **Settings** (gear) icon in the top right corner of the chat screen.
Enter your API key (e.g., for Qwen or compatible services) and tap **Save**.

![Settings API Key](/img/ai-assistant/settings-api-key.jpg)

### Chat History

Your conversations are saved locally. You can view past chats by tapping the **History** (clock) icon.

![Chat History](/img/ai-assistant/chat-history.jpg)

### Fixing Errors

When you encounter a compilation error, the AI Assistant can analyze it. It will provide a detailed explanation of the error and, in many cases, offer a **Proposed Change**.
You can simply tap **Accept** to automatically apply the fix to your code.

![Code Fix](/img/ai-assistant/code-fix.jpg)
