# Custom Block Generator

The **AI Custom Block Generator** makes creating custom blocks effortless. Instead of manually configuring every parameter and code snippet, you can simply describe what you want the block to do.

## How to use

1.  Open the **Add a new block** screen (usually found in the Developer Tools or Block Manager).
2.  Tap the **AI Assistant** icon in the top right corner.

![Access Generator](/img/custom-block-generator/step-1.jpg)

3.  The **AI Custom Block Creator** dialog will appear.

![Generator Dialog](/img/custom-block-generator/step-2.jpg)

4.  Enter a description of the block you want to create. For example: `login user`.
    Tap **Generate Definition**.

![Input Description](/img/custom-block-generator/step-3.jpg)

5.  The AI will automatically fill in the block properties, including the name, label, parameters, and color.

![Generated Properties](/img/custom-block-generator/step-4.jpg)

6.  Scroll down to see the generated code implementation. You can review and modify the code if necessary.
    Tap **Save** to create your new custom block.

![Generated Code](/img/custom-block-generator/step-5.jpg)
